# Acteurs et Cas d'Usage FamilyBalance

## Acteurs identifiés

- Parent
- Adolescent (plus de 12 ans)
- Psychiatre/Psychologue (Spécialiste)
- Administrateur

## Cas d'usage par acteur

### Parent

- Créer un profil enfant
- Remplir le survey
- Consulter le score
- Prendre un rendez-vous

### Adolescent

- Faire un self-assessment
- Accéder aux ressources éducatives
- Utiliser la messagerie

### Spécialiste

- Consulter le tableau de bord clinique
- Gérer le calendrier
- Mener la téléconsultation

### Admin

- Gérer les comptes
- Modérer les contenus
- Exporter les données anonymisées
